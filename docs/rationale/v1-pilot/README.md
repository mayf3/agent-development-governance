# V1 pilot rationale

This directory records the non-authoritative pilot basis for `AGENT_DEVELOPMENT_GOVERNANCE_V1`.

```text
AUTHORITY_CLASS = RATIONALE_AND_PROVENANCE
PRODUCT_AUTHORITY = NO
EXECUTION_MANDATE = NO
REPOSITORY_OR_RUNTIME_AUTHORIZATION = NO
```

The full initial simulation and R2 candidate were supplied to the formal authoring process. Their load-bearing findings, source digests, scenario matrix, required revisions, and dispositions are preserved in `SIMULATION_SYNTHESIS.md`. The final targeted resimulation is preserved in full because it is the direct authoring-readiness observation.

Files:

- `SIMULATION_SYNTHESIS.md` — bounded synthesis of the eight-round simulation, six required revisions, Research/life-primitives findings, and source hashes.
- `AGENT_GOVERNANCE_V1_R2_TARGETED_RESIMULATION_REPORT.md` — full four-test adversarial resimulation report.

These files explain why V1 was proposed. They do not create Product Contracts; only an accepted governing Spec can do that.
