# Agent entrypoint

Before non-trivial work:

1. read `.agents/README.md`;
2. read `.agents/local/README.md`;
3. read directly relevant Product Direction, Architecture/invariants, and accepted Specs;
4. read `.agents/skills/spec-governance/SKILL.md` and only the selected mode.

Classify independently:

```text
AUTHORITY_ACTION
PLAN_LEVEL
ASSURANCE_LEVEL
```

Only active accepted Product Authority creates long-lived obligations. A valid Execution Mandate may constrain one operation but cannot change Product Contracts.

Do not proceed through a load-bearing `SPEC_GAP`, invalid controlled mandate, inaccessible required Evidence, or unresolved live-authority gap. Do not treat code, tests, runtime, chat, Investigation, Task text, or newest document as higher authority.

When `DONE_WHEN` is met and no `EXPANSION_TRIGGER` fired, stop.
